    התקנה¶

    דרך HACS (מומלץ)¶

    1. פתחו את HACS וחפשו Dud Shemesh.
    2. היכנסו לאינטגרציה, לחצו Download והפעילו מחדש את Home Assistant.

    עדיין לא מופיע בחיפוש של HACS?

    האינטגרציה הוגשה לרשימת ברירת המחדל של HACS וההגשה ממתינה לבדיקה. עד שהיא תופיע בחיפוש, מוסיפים אותה כמאגר מותאם אישית:

    1. HACS ← ⋮ ← Custom repositories.
    2. Repository: https://github.com/bareli/dud_shemesh, Type: Integration.
    3. חפשו Dud Shemesh ← Download ← הפעילו מחדש את Home Assistant.

    התקנה ידנית¶

    1. העתיקו את התיקייה custom_components/dud_shemesh/ מהמאגר אל <config>/custom_components/.
    2. הפעילו מחדש את Home Assistant.

    הוספת האינטגרציה¶

    1. הגדרות ← מכשירים ושירותים ← + הוספת אינטגרציה ← Dud Shemesh.

    2. מלאו את הטופס:

      שדה משמעות
      ממסר חימום הממסר (switch.* או input_boolean.*) שמפעיל את גוף החימום החשמלי.
      חיישן טמפרטורת המיכל רשות. sensor.* מספרי במעלות צלזיוס.
      טמפרטורה רצויה ברירת מחדל 55 מעלות.
      הספק גוף החימום ברירת מחדל 2400 וואט. משמש לחישוב אנרגיה ועלות.
      נפח המיכל בליטרים, 0 = לא ידוע. משמש להערכת מספר המקלחות ולהערכת קצב החימום כשעוד אין נתונים.
      מחיר חשמל בשקלים לקוט״ש. ברירת מחדל 0.62.
      צריך מים חמים ב- חלונות נוחות כמו 06:30-08:00,19:00-21:00. משמשים את המצב האוטומטי.

    3. פתחו את דוד שמש בסרגל הצד.

    את כל השאר משנים אחר כך בהגדרות הפאנל. ראו הגדרות.

    כרטיס ה-Lovelace נרשם אוטומטית כמשאב של Lovelace, ואין צורך להוסיף אותו ידנית. אחרי עדכון, הפעילו מחדש את Home Assistant ורעננו את הדפדפן כדי לטעון את הפאנל והכרטיס החדשים.

    יותר מדוד אחד¶

    אפשר להוסיף את האינטגרציה שוב עבור דוד שני או בית נוסף. לכל רשומה יש מתזמן משלה וקובץ אחסון משלו. ראו כמה דודים.
